GPU raytracing for robots, simulators and anyone who needs a picture

A library, not an engine: pip install it, hand it your meshes and poses, and get images, depth and segmentation back. Path-traced beauty mode, thousands of worlds in one call, on an NVIDIA GPU or any CPU.

Every frame is rendered by neraulGraphics itself. The numbers in the corner of the stress tests were measured while that frame was being drawn.

What it does

One renderer, used three ways: fast pictures for a policy, beautiful ones for a person, and thousands of worlds at once for training.

Beauty mode

Path tracing with physically based materials (roughness, metallic, emission), bounced light, soft shadows, and sky or HDRI lighting with a sampled sun. Denoised so one sample per pixel looks clean.

Thousands of worlds

BatchRenderer draws many independent worlds, each with its own cameras, in one call. Poses and cameras can stay on the GPU, and images come back as tensors for PyTorch, JAX or Warp.

Sensors

Depth, surface normals and object IDs from the same rays as the picture, plus ray queries for LiDAR and range sensors. Depth is measured along the view axis, as a depth camera reports it.

Meshes and instancing

Triangle meshes are shared; instances place them. Moving a body only updates a small tree built on the GPU, so large moving scenes stay cheap.

Newton and MuJoCo

NewtonRenderer and MuJoCoRenderer turn a simulator's shapes into instances once, then update only poses. Batched Newton and MuJoCo Warp simulations read the GPU state in place.

Load models

ng.load("model.glb") reads glTF, GLB and OBJ with materials, colour textures, smooth normals and node hierarchies.

Runs anywhere

An NVIDIA GPU is used automatically; otherwise every CPU core is, with the same picture. Wheels for Linux, macOS and Windows. C++ users get find_package(neraulgraphics).

Clear errors

A bad scene raises ValueError (or std::invalid_argument) saying what is wrong, instead of crashing.

Quick start

Install, make a scene, render. The first picture is a few lines.

# Python 3.10 or later
pip install neraulgraphics

A first picture

import neraulgraphics as ng

red = ng.Material(diffuse_color=(0.5, 0.1, 0.1))
renderer = ng.Renderer(
    800, 450,
    spheres=[ng.Sphere((0, 0, -10), 2, red)],
    lights=[ng.Light((-10, 20, 10), intensity=1.5)])
camera = ng.make_camera((0, 1, 0), (0, 0, -10),
                        width=800, height=450)
for frame in range(64):   # more frames, smoother
    image = renderer.render(camera, frame)

Beauty mode

renderer.set_render_mode(
    ng.RenderMode.PathTraced, ng.PathTracing(bounces=4))
renderer.set_environment(ng.Environment(
    map=ng.procedural_sky(sun_elevation=0.7,
                          sun_strength=3.0)))  # or ng.load_hdr("sky.hdr")

for frame in range(32):   # holds still: refines itself
    image = renderer.render(camera, frame)

Thousands of worlds

batch = ng.BatchRenderer(
    64, 64, world_count, 1, spheres=spheres, lights=lights,
    floor=floor, meshes=meshes, instances=instances)
batch.set_instance_transforms(poses)   # CUDA tensors work
out = batch.render(cameras, fov=1.0, rgb=True,
                   depth=True, zero_copy=True)
rgb = torch.from_dlpack(out["rgb"])  # no copy

A simulator

from neraulgraphics.newton import NewtonRenderer

view = NewtonRenderer(model, 1280, 720)
view.beauty()                       # path traced, Z-up sky
for frame in range(300):
    step_simulation(state)
    image = view.render(state, frame=frame)

Prefer a window? ./raytracer --beauty after make raytracer opens the interactive viewer, and the examples in examples/ open their own.

Honest limits

  • NVIDIA GPUs only for now. The CPU backend gives the same pictures; AMD, Intel and Apple GPU backends are not built.
  • The denoiser follows a moving camera, but a moving object leaves a short trail, and converged images keep a small edge bias.
  • Batched worlds draw in the classic way, not in beauty mode.
  • Updating instances from NumPy pays for validating and copying every matrix; the cost grows with the instance count, as the table above shows.
